Favicon

Ikon kecil yang tampil di tab browser. Upload 1 gambar (disarankan PNG persegi, misal 512x512) — otomatis dipakai di semua halaman.

3 slot link sosmed di header

Nama & link tiap slot tampil di header semua halaman, lengkap dengan ikon otomatis kalau namanya mengandung "WA/WhatsApp", "Telegram", atau "Discord". Kosongkan nama untuk sembunyikan slot.

3 slot link di halaman watch (detail post)

Tampil di bawah tombol Buka Link/Unduh pada setiap halaman detail post. Ikon otomatis terdeteksi dari nama, misalnya "Tutorial PC", "Nonton TV", atau "Terbatas 18+". Kosongkan nama untuk sembunyikan slot.

3 slot link di halaman Kontak

Tampil sebagai tombol langsung di halaman Kontak (bisa WhatsApp, Telegram, Email, dll). Kosongkan nama untuk sembunyikan slot — kalau ketiganya kosong, halaman Kontak tidak menampilkan tombol apa pun.
